MyShift Backup

Last updated: August 30, 2026

Service

MyShift Backup is a private utility for storing and verifying MyShift database backups in the owner's own Google Drive account.

Authorized use

The utility is intended only for authorized MyShift backup operations performed by the application owner or other explicitly authorized users.

User control

The user remains in control of the Google Account used for storage and may revoke Google access or delete backup artifacts at any time.

Availability

The utility is provided for private operational use without a guarantee of uninterrupted availability. Backup and restore verification should continue to be monitored as part of normal MyShift operations.
