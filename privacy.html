Privacy Policy

MyShift Backup

Last updated: August 30, 2026

Purpose

MyShift Backup is a private utility used to create and restore backup copies of the MyShift application's database using the owner's own Google Drive account as off-device storage.

Google user data accessed

MyShift Backup requests the Google Drive OAuth scope https://www.googleapis.com/auth/drive.file. This scope allows access to files the user creates or opens with the application. MyShift Backup uses it only for backup artifacts that it creates or otherwise accesses through this scope.

How Google user data is used

The application may create, upload, list, verify, download for restore verification, and delete MyShift backup artifacts in Google Drive. These operations are performed only to provide backup, integrity verification, retention, and restore-verification functionality.

Storage

Backup artifacts are stored in the user's own Google Drive account. OAuth credentials and refresh tokens used by rclone are stored locally on the user's Mac. They are not stored in the MyShift source-code repository and are not transmitted to a separate MyShift application server.

Sharing and advertising

MyShift Backup does not sell Google user data. It does not share Google user data with advertisers, does not use Google user data for advertising, and does not use Google user data for profiling.

Retention and deletion

Backup artifacts remain in the user's Google Drive until removed by the configured backup retention process or manually deleted by the user. The user can also revoke the application's Google access at any time from their Google Account permissions and can remove the local rclone configuration to delete locally stored OAuth tokens.

Website data

This website does not use advertising, analytics, tracking scripts, or application cookies. The hosting provider may process standard network and security logs as described by its own service policies.

Contact

For questions about MyShift Backup, use the support contact displayed on the application's Google OAuth consent screen.
