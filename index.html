MyShift Backup

MyShift Backup is a private backup utility used by the owner of the MyShift application to store database backup artifacts in the owner's own Google Drive account.

Google Drive access

MyShift Backup requests only the Google Drive drive.file OAuth scope. It uses this access to create, upload, list, verify, download for restore verification, and delete MyShift backup artifacts that are accessible to the application under that scope. It does not request broad access to unrelated files in the user's Google Drive.

Data handling

Backup files remain in the user's own Google Drive. OAuth credentials and tokens are stored locally on the user's Mac by rclone and are not sent to a separate MyShift application server. MyShift Backup does not sell Google user data, use it for advertising, or use analytics or tracking on this website.

This website is intentionally minimal and contains no advertising, analytics, tracking scripts, or third-party embedded resources.
